## 데이터 연결

기존 M3/M5에서 확정된 지역코드 앞 두 자리를 시도 경계 코드에 연결한다. 광주·전남은 12 한 도형으로 보여주며 임의로 분리하지 않는다. 모든 관측기간을 동일한 2026.07 경계로 표시한다. M0~M4 및 공개 수치 파일은 변경하지 않는다.

종목별 시도 비율은 시군구의 한도가격 건수 합계 / 분모 합계다. 시군구별 비율을 평균하지 않으며 전국 ALL 행을 중복 합산하지 않는다. 실제 0%, 기록 없음, 30건 미만을 별도 표시한다.

시도 선택은 지도와 상세 패널만 갱신한다. 시군구 표에서 선택하면 기존 지역 필터와 시뮬레이션에도 적용된다. 시뮬레이션 계약에 없는 시도 코드를 넘기지 않는다.

## 재생성

일회성 Python 환경에 pyarrow와 shapely를 설치한 뒤 `python scripts/build_province_map.py`를 실행한다. 고정 URL에서 받은 파일의 SHA-256 및 16개 코드를 검사하고 `src/data/korea-provinces.json`을 생성한다. 웹앱 실행 시 외부 지도 API나 키가 필요하지 않다.

`npm test`는 모든 공개 지도 파일·종목의 시도 합계를 전국 합계와 비교하고, 코드 누락·중복 합산·단순 평균·0%/결측 혼동을 검사한다.
