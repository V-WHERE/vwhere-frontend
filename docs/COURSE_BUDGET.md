# 강좌 누적 선택과 가격 안내

## 사용자 동작

첫 강좌를 선택하면 가격·시설·종목·기간과 월 한도 대비 금액을 즉시 보여준다. 한도와 같은 강좌는 남는 한도 0원, 한도 초과 강좌는 초과액을 표시하며 추가 후보가 없어도 선택 정보는 유지한다.

추가 버튼으로 두 번째 이후 강좌를 계속 고른다. 선택할 때마다 모든 가격을 더하고 남은 한도 이내 후보를 다시 찾는다. 추가 강좌의 빼기는 한도와 후보를 복원한다. 첫 강좌를 다시 선택하거나 자료월·지역·종목을 바꾸면 조합을 초기화한다.

## 계산 계약

- M0~M4, 공개 JSON, M5 `m5-v1` 및 기존 `findCompanions`는 변경하지 않았다.
- `buildCourseBudget`은 기존 2개 조합 계약을 누적 선택으로 확장한다.
- 같은 관측월·같은 시군구·서로 다른 공개 ID·유효한 양수 가격을 사용한다. 강좌 기간이 관측월에 겹치는 기록만 사용한다. 서로의 시간표가 맞거나 실제 함께 수강 가능함을 보장하는 조건은 아니다.
- 추가 후보의 가격은 월 한도에서 선택 가격 합계를 뺀 금액 이하여야 한다. 이미 선택한 ID는 제외한다.
- 한도 초과 강좌는 첫 강좌 정보 열람용이며 추가 후보로는 나오지 않는다.
- 버튼 연속 조작에도 최신 선택 목록으로 추가 가능 여부를 재검사한다.
- 게시가격을 비교하는 기능이다. 모집 여부·시간표·최종 가격은 공식 신청 사이트에서 확인한다.

## 화면 표현

추가 후 금액은 ‘합계’와 ‘남는 한도’를 각각 표시한다. 시뮬레이션에는 변경 한도 안에 들어오는 강좌 수, 전체 대비 비율, 새로 들어온 강좌 수, 새 한도와 같은 가격의 강좌 수를 구분한다. 월별 기록 집계에는 건 단위를 사용한다. 가정 결과이며 미래 가격 예측이 아니다.

러너는 사용자가 승인한 생성 이미지 시안을 `public/images/runner-hero.png`로 적용했다. 동작 줄이기 설정에서는 움직이지 않는다.

## 검증

- 기존 전체 테스트와 누적 조합 테스트 19개 통과. 7월 실제 자료의 첫 선택 후보·합계·남는 금액이 기존 2개 조합 결과와 일치함을 확인했다.
- 브라우저에서 실제 탁구 20,000원 → 헬스 추가 25,000원 → 피클볼 추가 65,000원, 삭제 후 후보 복원 및 110,000원 도달을 확인했다.
- 185,000원 강좌 선택 시 강좌 정보와 75,000원 초과액을 확인했다.
- 320px·390px 모바일에서 가로 넘침 없이 추가 버튼과 금액을 확인했다. Enter 키 추가와 월 변경 초기화를 확인했다.
- 150,000원 가정의 8,293개 / 8,087개 / 7,856개 결과와 설명을 확인했다. 브라우저 콘솔 오류 없음.
