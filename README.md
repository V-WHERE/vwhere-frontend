# V:WHERE frontend

**V:WHERE**는 장애인스포츠강좌이용권의 가격 정보를 두 관점에서 보여준다. **이용자·보호자**는 월 한도 안의 강좌를 찾고 첫 강좌와 가격상 함께 볼 수 있는 추가 강좌를 확인한다. **공단·지자체 담당자**는 지역·종목별 한도가격 집중, 과거 가격 구성, 한도 변경 가정별 선택 폭을 비교한다.

이 저장소는 두 화면과 서비스 배포를 담당한다. 데이터 생성·검증은 [백엔드 저장소](https://github.com/V-WHERE/vwhere-backend)가 담당한다.

## 현재 상태

협업용 저장소를 초기화한 단계다. 실제 React 화면, 배포 URL, `package.json`은 아직 반영되지 않았다. 이 문서는 팀의 M5 화면 계약을 개발 시작점으로 정리한 것이다. 코드가 들어오면 실행·테스트·배포 명령을 실제 설정에 맞춰 갱신한다.

## 화면 흐름

헤더 오른쪽 위의 `이용자 | 담당자` 전환 버튼으로 두 화면을 오간다. 기본 화면은 이용자이며 지역·종목·자료월 선택은 화면을 전환해도 유지한다.

| 화면 | 사용 흐름 | 핵심 결과 |
|---|---|---|
| 이용자 | 지역·종목·자료월 선택 → 한도 내 강좌 선택 → 추가 가격 후보 확인 → 공식 신청 사이트 이동 | 첫 강좌와 추가 후보의 게시가격, 두 가격 합계, 한도 안에 남는 금액 |
| 담당자 | 지역·종목별 지도·표 → 과거 가격 구성 → 새 한도와 가격 반응 가정 조작 | 한도가격 비율과 분모, 가정별 한도 내·새 진입 강좌 수 |

기본 자료월은 **2026년 7월 관측 자료**다. 2026년 8월을 선택할 때는 자료량 검토 표시를 한다. 지도에는 같은 숫자의 표를 함께 제공한다.

## 화면 데이터 계약

팀의 `M5_CONTRACT.md`가 기준이며 스키마 버전은 `m5-v1`이다. M5 공개용 JSON을 정적 자산으로 배치하거나, 백엔드와 합의한 동일 필드의 API를 사용한다. 데이터가 들어오기 전에는 수치를 화면 코드에 고정하지 않는다.

| 데이터 | 화면 사용처 |
|---|---|
| `meta.json`, `catalog/YYYYMM.json` | 자료월 선택, 이용자 강좌 목록과 가격 조합 |
| `lookups.json`, `map/{period}_{unit}.json` | 지역·종목 선택, 담당자 지도·표 |
| `history.json` | 과거 가격 구성과 동일 강좌 이력 |
| `sim_bins/{period}_{unit}.json` | 한도 변경 가정별 선택 폭 계산 |
| `simulation_reference.json` | 대표 시나리오 결과 대조 |

M5의 `findCompanions`와 `simulateFromBins` 계산 함수가 확정 기준이다. 함수 이식이나 입력 구조 변경이 필요하면 백엔드와 계약·테스트를 같이 갱신한다.

## 화면 문구와 접근성

- 이용자 조합은 **“가격상 함께 볼 수 있는 강좌”**다. 게시가격이 맞는다는 뜻이며 현재 모집·수업시간·최종 가격은 [공식 신청 사이트](https://dvoucher.kspo.or.kr/main.do)에서 확인하도록 연결한다.
- 담당자 시뮬레이터는 **“가격 반응 가정별 선택 폭”**이다. 과거 관측 그래프와 시나리오 결과를 시각적으로 분리한다.
- 값 없는 지도 셀은 `기록 없음`, 분모 30 미만은 `표본 적음`과 분모를 표시한다. 0%와 결측을 구분한다.
- 화면 전환과 필터는 키보드로 조작할 수 있어야 하며, 색만으로 상태를 표현하지 않는다. 모바일과 200% 확대에서도 두 화면을 확인한다.

## 개발 시작 순서

1. 팀의 `M5_CONTRACT.md`, `FRONTEND_HANDOFF.md`와 공개 JSON 샘플을 확인한다.
2. React·TypeScript 앱을 구성하고 이용자/담당자 전환 및 공통 필터를 구현한다.
3. 가격 조합과 지도·표·시뮬레이터를 실제 M5 데이터에 연결한다.
4. 대표 수치, 빈 결과, 데이터 오류, 키보드·모바일 동작을 확인한 뒤 배포한다.

작업 규칙은 [AGENTS.md](AGENTS.md)에 있다. 초기화 이후 변경은 목적별 브랜치와 PR로 반영한다.
