# V:WHERE frontend

장애인스포츠강좌이용권의 공개 게시가격을 이용자와 담당자 관점에서 살펴보는 React + TypeScript 프론트엔드입니다.

## 실행

```bash
npm install
npm run dev
```

개발 서버는 `http://127.0.0.1:5173/`에서 열립니다. 포트가 이미 사용 중이면 다른 포트로 조용히 변경하지 않고 오류를 표시합니다.

기본 자료월은 2026년 7월입니다. `public/data`의 M5 공개 JSON과 `src/lib/m5_logic.mjs`의 확정 계산을 사용합니다. 신청 링크는 모두 장애인스포츠강좌이용권 공식 사이트로 연결됩니다.

## 데이터 연결

현재 프론트엔드는 백엔드 API가 아니라 같은 배포의 `/data` 경로에 포함된 M5 `m5-v1` 공개 JSON을 `fetch`로 읽습니다. 팀 문서와 저장소에는 승인된 API 기본 주소·엔드포인트·인증·CORS·오류 응답 계약이 아직 없습니다. API로 전환하려면 이 정보와 함께 catalog, map, history, sim_bins 응답이 현재 M5 공개 스키마와 호환되는지 확인해야 합니다. 계약 없이 임의 API나 mock 주소를 연결하지 않습니다.

## 검증

```bash
npm run lint
npm test
npm run build
npm run preview
```

`npm test`는 전체 공개 자료월 계약, 가격 조합의 한도 경계·동일 ID·날짜·지역·결과 0 조건, 지도 셀의 비율·분모·실제 0%·표본 적음, 대표 시뮬레이션 수치와 한도·집계단위 변경을 확인합니다. `npm run preview`는 빌드 결과를 로컬에서 확인할 때 사용합니다.

## 화면 계약

- 이용자: 자료월·지역·종목 선택 → 첫 강좌 선택 → 남은 한도에 맞춰 추가 강좌를 연속 선택·제거 → 공식 신청 정보 확인
- 담당자: 기간·집계단위·지역·종목별 한도가격 수치 → 한도 변경 가정 → 과거 관측
- 모집 여부, 수업시간, 최종 가격은 공개 자료에 없으므로 공식 신청 사이트에서 확인합니다.
- 시뮬레이션은 동일 강좌 집합에 적용한 산술 가정이며 미래 가격이나 실제 지급액 예측이 아닙니다.

## 지도형 가격 현황

담당자 화면의 실제 행정구역 지도에서 시도를 선택하면 해당 지역 비율·집계 건수·가격 분포·시군구 표가 함께 바뀝니다. 시군구를 고르면 시뮬레이션에도 같은 지역이 적용됩니다. 모바일에서는 지도를 위에, 상세를 아래에 표시하며 키보드와 지역 선택 목록으로도 이용할 수 있습니다.

경계 출처·라이선스·재생성 방법은 [지도 경계 문서](docs/MAP_BOUNDARIES.md)를 참고하세요.

강좌 누적 선택, 한도 초과 표시와 검증 범위는 [강좌 조합 문서](docs/COURSE_BUDGET.md)를 참고하세요.
